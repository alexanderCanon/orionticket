# Antes de comenzar a trabajar definir los agentes principales:

## AGENTS.md
Para trabajar con OpenCode, Codex, Jules

## CLAUDE.md
Para trabajar con Claude Code 

## GEMINI.md
Para trabajar con Gemini

Estos archivos md definen al agente principal, les da contexto, memoria y algunas reglas, también dan identidad a cada sesión y luego pueden definirse sub agentes para tareas especificas
La documentación debe estar tipo libro con un índice bien claro para evitar que el agente de IA lea todo de golpe y consuma los tokens

Para potenciar más el trabajo se recomienda:
- Instalar skills permite brindar herramientas para acelerar el desarrollo
- Agregar MCP para crear puentes entre la IA y aplicaciones externas, muy recomendado
- Indicar en cada sesión que debe crear una rama nueva y trabajar basada en ella, mantener consistente la documentación
